Umininn TV 目標電腦 CPU／記憶體對照工具
=======================================

適用 Windows 10／11、Windows PowerShell 5.1。
不用安裝 Node、Python 或額外插件。Firefox、Chrome、Edge 均可。

開始前
------
1. 把整個 ZIP 解壓到目標電腦的普通資料夾，例如桌面。
2. 開 start.html，把「TV 效能檢查」連結拖到瀏覽器收藏列。
   或按「複製書籤網址」，在書籤管理員新增／更新「TV 效能檢查」。
3. 開好原本的 Umininn TV 觀看頁。建議先以 10 或 20 台測試。
4. 盡量只留下該款瀏覽器的測試視窗／分頁。其他工作可用另一款瀏覽器。
5. 雙擊 Start-TV-Performance.cmd，選擇 Firefox／Chrome／Edge。
   每段預設採樣 30 分鐘，先暖機 60 秒，每 5 秒記錄一次。

兩段實測流程
------------
第一段 off：
  在 Tampermonkey 手動停用播放器 userscript，重新整理觀看頁。
  等候影片恢復、保留相同台數／分佈／畫質，再執行「TV 效能檢查」書籤。
  書籤只下載一份小 JSON，不會持續監控。
  回工具按 Enter，工具只搜尋 Downloads 內本工具前綴的最新 JSON；
  自訂下載資料夾可按 B，用檔案選擇器指定該 JSON。
  工具核對腳本確實關閉後，開始暖機及採樣。
  請切回觀看頁保持前景，不要最小化瀏覽器。
  第一段完成後，在觀看頁再執行一次書籤，提供 off/end 檢查點。

第二段 on：
  在 Tampermonkey 手動啟用同一版本的播放器 userscript，重新整理觀看頁。
  還原同一台分佈、畫質、視窗大小、硬體加速及音量。
  再執行書籤提供 on/start 檢查點，暖機後採樣第二段。
  完成後，再執行書籤提供 on/end 檢查點。

兩段中間由你手動切換 Tampermonkey；工具不會改動腳本管理器。
採樣期間不要更新 userscript 版本、切台、改畫質、開新分頁或進行下載。
兩段實測預設共約 62 分鐘，另加你操作及等待影片恢復的時間。

停止與資料
----------
在工具視窗按 Q 可停止並保存已取得資料。暖機也可按 Q 停止。
每個採樣點都會儲存，因此強制關閉視窗後通常仍有上次保存的檔案；
但強制結束／關機可能留下未完成階段，這種結果不能當完整 A/B。

結果在工具旁的 results\日期時間-代號\：
  summary.json       分析入口，含採樣條件、檢查點及摘要
  samples.csv        每次採樣的 CPU／記憶體總值
  processes.csv      所選瀏覽器的每個處理程序數值及啟動時間
  report.html        可直接開啟的結果摘要
  off/on-...json     只保留所需欄位的階段檢查點

完成後請把整個結果資料夾傳回，保留原始數據方便核對。
工具不會自動上傳，也不會替你壓縮任何其他資料夾。

數字怎樣看
----------
CPU 100% 代表用滿一個邏輯 CPU 核心；多核心總值可以超過 100%。
「全機容量 %」是上述數字除以邏輯 CPU 數，方便理解整機比例。
Private MiB 是瀏覽器處理程序私有提交記憶體，不等於實體 RAM 使用量。
Working Set 是駐留記憶體，跨處理程序加總可能重複計算共用頁。
記憶體比開始時高，不等於已證明有洩漏；影片緩衝、快取也會影響。

重要量測範圍
------------
本工具量的是整個所選瀏覽器，包括其其他視窗／分頁／profiles；
不是單一 TV 分頁。Firefox 亦納入舊版使用的 plugin-container。
它只讀取程序 CPU／記憶體／啟動時間，不讀瀏覽器命令列或 profiles。

書籤只在你執行當下讀取：
  - userscript 版本及控制準備標記
  - 播放格數量、原生媒體播放／暫停／錯誤／靜音／有聲數量
  - 頁框主機名稱、瀏覽器版本及去除查詢字串的觀看頁路徑
  - 頻道組合、佈局及原生音量設定的 SHA-256，用來核對前後是否一致
    （原生音量以 0.001 精度比對，避免浮點誤差）
頻道 key 可能包含播放網址，只在該頁記憶體內作雜湊，不輸出原值。
iframe 的 src 只用來取得主機名稱，不輸出其路徑或 query。
它不讀聊天、cookies、登入資料或原生影片 src/currentSrc，不輸出串流網址；
沒有監察器、採樣計時器、持續紀錄或網絡上傳。
跨網站頁框內的實際播放／音量狀態、幀數、畫質及每個子頁腳本版本
無法由此書籤讀取；外站聲音及畫質請手動保持相同。

真實網站的兩段測試仍可能有廣告、碼率、串流失敗及其他程式負載差異。
報告會標示可檢查的台數／頻道／佈局／腳本／原生播放與音量差異，
但無法驗證全部外因。
處理程序可能在兩次採樣之間退出，CPU 結尾的一小段可能未被計入。
請把結果當作實機觀察性對照，不能把任何差距全都歸因於 userscript。

安全與啟動
----------
Start-TV-Performance.cmd 使用 ExecutionPolicy Bypass 僅限這次 PowerShell
處理程序，不會修改全機或帳戶的執行原則。企業群組原則可能仍會阻止執行。
工具不要求管理員、不結束任何程序、不自動關分頁、不自動切換腳本，
也不修改網站、音量、播放來源、登錄資料或登入狀態。
