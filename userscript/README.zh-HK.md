# Umininn TV 播放器控制 Userscript

版本：1.0.13。Chrome、Edge、Firefox 使用同一份 `umininn-tv-player.user.js`，透過腳本管理器安裝。腳本更新不需要向 Mozilla 送簽；安裝內容由腳本管理器保存，重啟瀏覽器後仍會保留。

## 1.0.13 播放器亮框覆蓋層

Twitch、Kick、其他 iframe 及原生影片的亮框改在播放器外的獨立覆蓋層繪畫，避免 iframe 蓋住上方和左右邊框。看更台及播放控制各自管理標示，放大、搬位、調整視窗或替換播放器後會重新對齊；覆蓋層不攔截滑鼠或修改播放、音量及影片來源。更新腳本後須重新整理觀看頁才生效。

## 1.0.12 縮放播放器標示及選單定位

修正 Kick 縮放 iframe 蓋住 highlight 邊框及內外層圓角不一致的問題，邊框改在影片上方繪畫並保持點擊穿透。滑鼠進入影片格時，若選單內對應項目未完全可見，會以最小距離捲動該選單；已可見時不移動，亦不持續拉回手動捲動的位置。

## 1.0.11 選單與播放器雙向標示

開啟「看更台」或「播放控制」後，滑鼠指向某台的選項／控制列會標示對應影片格；指向影片格則標示選單內對應項目。名稱重複、移位或放大後仍按實際播放器配對；關閉選單、播放器被移除或離開頁面時會清理標示。標示不攔截播放器點擊，也不修改播放或聲音。

## 1.0.10 放大格開聲

按普通觀看時每格右上角的「放大一級」，成功放大後會先靜音全部播放器，再將該格音量設為 100% 並開聲；連續放大不同格時以最後一次為準。其他格只靜音，保留音量數值。縮小、搬位及放大模式的拖拉不會切換聲音，亦不會啟動暫停的影片或重載播放器。

尚未就緒的播放器會作短暫等待；如有播放器未能確認靜音，便保留目標靜音並顯示提示，避免同時多台開聲。在「播放控制」內手動操作聲音或恢復播放，會取消尚未完成的自動切聲。更新腳本後須重新整理觀看頁才生效。

## 1.0.8 播放控制台名覆蓋層

開啟「播放控制」時，同時在各播放器格上顯示台名。關閉、按 Escape 或閒置 30 秒自動收起後，台名也隨之隱藏；「看更台」仍開啟時則繼續顯示，兩個面板同時開啟也只顯示一套台名。標籤不攔截滑鼠或觸控，不會重載影片。

## 1.0.7 播放器台名

「播放控制」的播放器列改用網站的台名，例如「火」、「KA」或「g（廣州電視）」。交換位置時名稱跟隨播放器，改名會同步更新；沒有台名時沿用平台／頻道 ID。名稱以純文字顯示，不會重載影片。

## 1.0.6 快捷全部靜音

「播放控制」左邊新增小型 🔇 按鈕，直接執行面板內的「全部靜音」。連按仍保持全部靜音；滑鼠提示和輔助讀屏名稱均為「全部靜音」。

## 1.0.5 閒置選單關閉

「播放控制」及「看更台」面板在最後一次操作後閒置 30 秒自動收起。面板內的滑鼠移動、點擊、觸控、鍵盤、調整音量及捲動會重新計時；背景播放器狀態及頻道清單刷新不會延長。逾時只關閉面板，不套用尚未確認的選台或改變播放、音量及靜音。重新開啟會從頭計時。

## 1.0.4 AngelThump 初載控制列修正

影片首次正常播放後，如果滑鼠不在播放器內、未用鍵盤操作、沒有正在使用的設定選單或控制項焦點，腳本會送一次原生 `mouseout`，讓 AngelThump 自己收起載入時殘留的控制列。已在播放的台會直接檢查；較晚載入的台用 capture `playing` 事件等待，完成首次檢查後移除這個監聽，不會輪詢或重複嘗試。暫停、載入中及結束的影片不會被強制收起。

滑鼠仍可正常叫出控制列；在播放器內使用鍵盤時，腳本送 `mousemove` 叫出原有介面，沿用平台原本的自動收起倒數。因 React 非同步顯示介面，腳本初次收起後，首次從容器／body 按 Tab 只叫出控制列並保留焦點，下一次 Tab 照常移動；其他播放快捷鍵不攔截。不點擊控制項、不修改播放或音量、不自行改變焦點，也不永久用 CSS 隱藏控制列。離線畫面沿用平台顯示。離開文件／進入快取時會移除新增的兩個事件監聽，1.0.3 的 Logo 隱藏及原有更新網址／權限維持不變。

## 1.0.3 AngelThump 橫幅修正

在本站觀看 AngelThump 時，腳本收到已核准父頁的探測後，在該播放器文件加上一份樣式，只隱藏指向 AngelThump Patreon 加入頁的連結。初始載入、稍後出現及 React 重新建立的「Become a patron」橫幅都會隱藏，不用先把滑鼠移入再移出；播放、暫停、音量、畫質及原有控制列不變。

這項處理不需要新增權限、後端代理或背景輪詢，不會改用 Patreon 伺服器、不會重載影片，也不會套用到直接開啟的 AngelThump 分頁、其他播放器或未核准網站。離開播放器文件時移除樣式；從瀏覽器快取返回後，重新收到核准探測才套用。更新至 1.0.3 後，重新整理觀看頁生效。

## 1.0.2 自動更新

腳本使用 GitHub Pages 的固定更新網址。每部電腦、每個瀏覽器先安裝或更新至這版一次，並允許管理器自動檢查及安裝更新，之後便無須每次重新貼上。已開啟的觀看頁在更新後重新整理才會使用新版；各瀏覽器不會同時即時切換。

## 1.0.1 載入等待修正

修正已連線的 Twitch iframe 建立空 `<video>`（`readyState=0`）後被過早視為就緒的問題。自動偵測現在要等影片 metadata 載入，或明確可用的 Twitch Play 按鈕出現，再穩定 600ms 才加入恢復佇列；尚未就緒的台不再提前消耗一次恢復，其他已就緒的台仍先處理。整輪仍以 30 秒為限，沒有背景持續重試。

送出恢復指令前會再用最新狀態核對一次；排隊期間失去就緒狀態，或 30 秒到期仍未就緒的台，會列為未就緒，不會強行送出恢復。

這項修正不代表所有 Firefox 暫停問題都已確認原因。如果 Firefox 拒絕腳本啟動播放，仍需在原播放器按播放，或在 Firefox 為該網站調整自動播放權限。[Mozilla 自動播放說明](https://support.mozilla.org/zh-TW/kb/block-autoplay)

## 安裝

1. 在各個要使用的瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/)。已使用 Violentmonkey 的 Firefox 亦可使用同一份腳本。
2. 停用舊的「Umininn TV 播放器控制」擴充功能，以及其他相同用途的舊腳本。
3. 在首頁「台務 → userscript」開啟腳本視窗，按「安裝／更新」，再在 Tampermonkey 的安裝畫面確認。亦可直接開啟 [線上安裝網址](https://umininn-gh.github.io/tv/userscript/umininn-tv-player.user.js)。已安裝舊版時，使用同一個腳本的更新畫面，避免建立重複腳本。確認腳本已啟用。[官方安裝方法](https://www.tampermonkey.net/faq.php?q=Q102)
4. Chrome／Edge 如顯示需要執行權限，在 Tampermonkey 的擴充功能詳細資料開啟「允許使用者指令碼／Allow User Scripts」；較舊版本按管理器提示開啟開發人員模式。[官方權限說明](https://www.tampermonkey.net/faq.php?q=Q209)
5. 確認腳本管理器可在本站及腳本列出的播放器網域執行，重新整理 Umininn TV，登入並開始觀看。

如管理器未攔截安裝連結，仍可按「複製全部」，在管理器新增腳本的編輯器刪除預設範本，貼入完整內容並儲存。已有舊版時，在原腳本編輯器取代全部內容；不要另外新增一份。Violentmonkey 亦可使用相同網址或從工具列「＋」開啟新腳本編輯器。[官方說明](https://violentmonkey.github.io/guide/creating-a-userscript/)

這個一次性的安裝／更新步驟須在每部電腦、每個瀏覽器完成；沒有依賴管理器帳戶同步。

## 使用

- 網站頂部「🎚 播放控制」開啟控制選單，可全部／逐台靜音、開聲及調整音量。
- 「↻ 偵測恢復」重新讀取各台狀態，已播放／緩衝中的台會略過，對可控制而未播放的台各嘗試恢復一次。逐台的「恢復播放」亦保留。
- 在「看更台」按「開始觀看」，各台就緒穩定後加入本輪恢復，不必等齊慢台；載入等待最多 30 秒，同時最多 4 項恢復操作。
- 改音量及靜音不重載 iframe，不會為此恢復人手暫停的台。來源不支援、尚未連線或瀏覽器拒絕自動播放時，會顯示狀態；必要時在原播放器按 Play。
- 登入後才建立的網站介面、新增／移除播放器，以及 CSS 搬位均沿用現有處理。選單標題顯示腳本版本。

支援範圍沿用原擴充功能：本站原生 HTML 媒體，以及 `player.twitch.tv`、`player.kick.com`、`ok.ru`、YouTube／YouTube No-Cookie、AngelThump、GoodGame 指定播放器主機內可辨識的 HTML 媒體。實際可用程度仍取決於播放器結構、來源及平台政策；未知 BS 網域或巢狀跨來源播放器不會自動獲得控制權限。

## 更新

確認 Tampermonkey 的更新檢查週期不是「永不／Never」，並允許腳本自動更新。如管理器提供「自動安裝／Automatic installation」設定，亦要開啟，否則可能只檢查及提示新版。新版 Tampermonkey 將更新檢查與自動安裝分開處理。[官方更新記錄](https://www.tampermonkey.net/changelog.php?locale=en&more=true&show=dhdg)

之前手動貼入或在管理器修改過的腳本，可能未啟用自動更新；請先從上面的線上安裝網址完成一次安裝／更新，再確認設定。之後集中修改程式庫並發佈，避免在各瀏覽器的腳本編輯器另作修改。需要立即更新時，可在管理器手動檢查更新，或再次開啟安裝網址。更新完成後重新整理觀看頁。

腳本標頭的 `@updateURL` 指向 [版本標頭](https://umininn-gh.github.io/tv/userscript/umininn-tv-player.meta.js)，`@downloadURL` 指向 [完整腳本](https://umininn-gh.github.io/tv/userscript/umininn-tv-player.user.js)。管理器檢查 `@version`，發現較新版本時下載完整腳本。[Tampermonkey 更新標頭說明](https://www.tampermonkey.net/documentation.php?q=update_url)

開發者修改來源後，須提高 `tools/build-player-userscript.cjs` 的 `RELEASE_VERSION`，重新建置，提交產出的 `.user.js`、`.meta.js` 及來源，再部署 GitHub Pages。只改程式碼而不提高版本，不會觸發管理器自動更新。保留 `@name` 和 `@namespace`，讓管理器識別為同一個腳本。`.meta.js` 只有版本標頭，安裝請使用完整 `.user.js`。

## 網站的聲音偏好同步

本程式庫的 `tv-app.js` 與 `admin.html` 已加入同頁聲音偏好接收，讓「全部靜音／開聲」後增減選台仍沿用該選擇，並保留仍在播放的 iframe。這項網站修正須隨網站部署才會在正式網址生效；腳本本身的音量、靜音及恢復控制可獨立運作。

## 權限與資料

腳本只匹配本站指定觀看頁及固定 HTTPS 播放器主機，不匹配 `localhost`、管理頻道資料頁或任意網站；即使手動貼入其他頁面，啟動時亦會重新核對網址。外站播放器只有收到已核准父頁的探測後才建立控制器。

沒有要求 `GM_*` 資料儲存、跨來源請求或 `unsafeWindow` 權限，沒有遠端 `@require`、遙測、憑證處理或持久控制偏好。模組封裝在私有作用域，跨頁框指令只在本機瀏覽器傳遞；每次文件會有獨立隨機識別，舊文件、錯誤來源及重複指令會被拒絕。腳本管理器和直播平台本身的資料處理由各自政策負責。

Tampermonkey 使用 `@sandbox DOM`，Violentmonkey 使用 `@inject-into content`；只需 DOM 操作。這些設定及未要求特權 API 的標頭，不會要求腳本取得頁面內的 JavaScript 變數。相關文件：[Tampermonkey sandbox](https://www.tampermonkey.net/documentation.php?q=sandbox)、[Violentmonkey metadata](https://violentmonkey.github.io/api/metadata-block/)。

## 建置與驗證

```powershell
node tools/build-player-userscript.cjs
node --test "tests/player-userscript-*.test.cjs" "tests/player-extension-*.test.cjs"
```

建置把 `browser-extension/shared/` 的媒體、Twitch 及恢復流程和控制介面，與 `userscript/angelthump-logo.js`、`transport.js`、`bootstrap.js` 合成單一檔案。不要手動修改產出的 `.user.js` 或 `.meta.js`；修改來源後提高版本並重新建置。輸出是本資料夾的發行檔及版本標頭，以及 `outputs/player-userscript/` 的相同副本。

瀏覽器整合測試可選用 `UMININN_BROWSER_TESTS=1` 執行，需可用的 Playwright 與相應瀏覽器引擎。預設 Chromium／Edge；設定 `UMININN_BROWSER_ENGINE=firefox` 可測 Firefox。測試把實際腳本注入網站／跨來源播放器模型，驗證真實 `postMessage` 及 HTML 媒體控制；這不等於已在 Tampermonkey／Violentmonkey 或三款瀏覽器實際安裝，也不代表所有外站直播已驗證。
