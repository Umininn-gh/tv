連線以管理共用清單

唯讀

可先查看頻道；輸入此程式庫的 GitHub 存取權杖後便可儲存。

權杖只留在這個視窗的記憶體，關閉或中斷連線後需重新輸入。

第一次使用：設定 GitHub 權限
  1. 開啟 GitHub 權杖設定，建立 fine-grained personal access token。
  2. Resource owner 選擇 此程式庫的擁有人，Repository access 選 Only select repositories，然後選取 tv。
  3. Repository permissions 的 Contents 選 Read and write，再產生權杖並貼到上面的欄位。

只有本身有程式庫寫入權限的 GitHub 帳戶能儲存變更。

疑似失效台檢查

人工審核

掃描全部現有台，分開核對帳戶、入口和直播狀態，列出證據與原因。沒有任何自動刪台；查詢失敗及離線會另外標示。

可先掃描；連線 GitHub 後才可儲存入口修改或刪除。

可直接掃描、保留標記及重查；要修改入口或刪除，請先在上方連線 GitHub。

    「保留」只記錄審核決定，下一次仍會檢查。歷次核查及審核標記保存在這個瀏覽器；修改與確認刪除才會更新共用清單。
